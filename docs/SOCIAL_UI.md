# SNS運用画面

## 投稿を準備する

1. 「投稿を作成」でInstagram・TikTok・X・Threadsから投稿先を選択します。複数選択できます。
2. 本文を入力し、画像・動画・ファイルを添付します。本文は2,200文字、添付は最大4件・各50MBです。
3. 端末の現地時間で公開予定を指定し、「予約を保存」を押します。

PCでは右側、スマホでは入力欄の下に内容確認のプレビューを表示します。画像と動画は端末内のファイルから表示されます。保存前の画像プレビューのためにファイルをサーバーへ送信することはありません。動画編集の結果は保存後に履歴から確認します。

プレビューは実際のSNS表示を再現するものではありません。現在は予約内容を保存する機能です。SNSへの自動公開と受信箱の同期は準備中です。投稿先のAPI情報を登録しても、自動公開は始まりません。

## 予約と履歴を確認する

- 予約一覧は公開予定日時の早い順に表示します。
- 上部の件数カードから、予約・下書き・要確認の投稿へ移動できます。全体件数は検索や絞り込みの影響を受けません。
- 投稿履歴は「すべて」「予約済み」「下書き」「公開済み」「失敗」で絞り込めます。検索と状態の条件は同時に適用されます。
- 検索対象はタイトル・本文・担当者・SNS名です。該当なしの表示から条件をクリアできます。
- 予約のキャンセルは下書きへ戻します。下書きと失敗した投稿は履歴から再予約できます。
- この画面内でメニューを移動しても、作成中の本文・投稿先・添付は保持されます。再読み込み・タブを閉じた場合は保存前の入力が失われます。

## スマホとキーボード

スマホは右上のメニューボタンから画面を切り替えます。移動後にメニューが閉じます。Escapeでも閉じられ、メニューボタンへフォーカスが戻ります。キーボードでは先頭の「作業画面へ移動」リンクから作業領域へ移動できます。

## 実装

- `app/social-console.tsx`: 通常利用者の画面と既存の操作処理。
- `app/social-design.css`: `.social-app` / `.social-auth` 内のデザイン。
- `app/lib/post-list.ts`: 検索・状態絞り込み・予約の日時順表示。
- 既存の認証、所属店舗、共有gourmetのSNSテーブル、保存処理、権限、非公開ファイルは従来の構成を使います。
- ユーザー指定の4種類のSNSロゴ画像はそのまま使用します。
- 確認用データを使うローカルのUI検証画面はリポジトリ外で作成し、公開アプリへ含めません。
